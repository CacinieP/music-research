# Music Research

Music understanding & generation research repository.

## Scope

- **Audio Engineering** — DSP, feature extraction, audio processing pipelines
- **Music Information Retrieval (MIR)** — tag prediction, source separation, transcription, similarity
- **Generative Models** — symbolic music generation, audio synthesis, singing voice synthesis
- **Foundation Models for Music** — large-scale pre-training, multi-modal music understanding

## Directory Structure

```
docs/
  surveys/    — literature reviews and paper summaries
  notes/      — technical notes and experiment logs
src/          — code and experiments
references/  — curated paper lists and resources
```

## Research Topics

### Music Understanding
- Automatic music tagging & classification
- Music transcription (piano roll, guitar tab, drum)
- Source separation & remix
- Music emotion / mood recognition
- Beat & tempo tracking, chord recognition

### Music Generation
- Symbolic music generation (MIDI, ABC notation)
- Audio-level generation (waveform, spectrogram)
- Singing voice synthesis
- Interactive / real-time generation
- Controllable generation (genre, emotion, instrument)

### Audio Engineering
- Feature representations (mel-spectrogram, chroma, VQT, etc.)
- Neural audio codecs (EnCodec, SoundStream, DAC)
- Diffusion-based audio models
- Real-time audio processing pipelines
