    内容审校记录（2026-09-19）¶

    本次按原论文、作者项目页、官方 API、数据发布页与法律机构原文审校。修订覆盖研究笔记的中英文版本、文献导读、参考文献、数据集目录、示例代码、部署与复现说明。

    实质修订¶

    • 音频与 MIR：更正音频编解码器与 token 表示、CFG 参数口径、转录指标和数据划分；为采样/时频/码率公式补充适用条件。
    • 音乐生成与歌声：区分模型代际与任务，修正 MusicLM、MusicGen、Jukebox、Stable Audio、SingSong、XiaoiceSing、VISinger 等的归属或技术描述；纠正歌声数据集规模。
    • 乐理与风格：更正七和弦、移调、声部连接、简单/复合拍等；将文化与风格判断从普遍规则改为带上下文的描述。
    • 评测：区分分布距离、配对重建、语义匹配、人类偏好与描述性统计，修正 FAD 与 F0 等公式和前提，删除不存在的指标/API。
    • 引用：核对标题、作者、年份与 URL，移除错配条目和无法核实的精确数字。原稿引用的 SongBench arXiv 号实际对应宇宙射线论文。
    • 版权与数据：区分作品/录音/标注/模型许可，纠正 CC 等于任意商用、合法获取等于合理使用等错误推断；删去官方未披露的和解金额。
    • 示例：修正编解码返回值、模型标识、旋律条件 API、MIDI 库接口、调性检测、概率归一化、静音除零和输出目录问题。

    如何理解此次核对¶

    内容修订以可追溯的来源为依据，关键出处附在各节。无法核实的条目删除或明确标注，不将其列为已证实结论。正文较原稿缩短，主要去除了重复说明、无来源排行榜、虚构 API 及失去条件的绝对结论。

    CPU 示例采用合成音频/MIDI与已知数学结果验证。大型模型的代码只做官方接口核对，未执行权重下载、GPU 推理、训练或主观听音，因此不声称独立复现论文性能。商业产品与法律信息是本次日期的资料核对，不是持续更新的榜单或具体项目法律意见。

    网站与 Wiki 从同一份 Markdown 生成。发布前检查本地链接、锚点、源公式与 HTML 一致性和 MathJax 解析，并在发布后复核线上内容。

    本次验证结果¶

    • 9 项 CPU 测试通过：音级与调性、熵归一化、SNR、静音/立体声重采样、STFT 重建与 440 Hz 音高、MIDI token 往返、极端有限输入，以及全部 Python 示例语法。运行环境为 macOS arm64、Python 3.13，依赖版本随仓库记录。
    • 30 篇源 Markdown 构建为 33 个内容页面，另含 404 页；所有本地链接、锚点和资源检查通过。
    • 47 段 LaTeX 在源文、站点和 Wiki 导出中保持一致；MathJax 解析无错误，GitHub Markdown 渲染单独检查。

    实测同时核清了两处容易误判的细节：预计算 CQT 转 chroma 时须一致指定每八度 bin 数；MIDI tokenizer 默认对速度量化，往返应比较音高与节拍，不能要求秒级时间完全不变。
