# AI 音乐生成评测：指标、协议与开放问题

AI 生成音乐的质量评测实践指南。涵盖人类评测协议、自动指标（分布/嵌入/感知）、文本-音频对齐、评测框架，以及自动指标与人类判断之间的鸿沟。

---

## 1. 为什么音乐评测难

音乐是多维度的：

| 维度 | 变化范围 | 重要性 |
|------|---------|--------|
| **音质** | 清晰度、保真度、噪声水平 | 基本音频质量 |
| **连贯性** | 结构逻辑、乐句流畅度 | 是否像"音乐"？ |
| **风格保真** | 流派匹配、音色准确 | 是否匹配目标风格？ |
| **新颖性** | 原创性、惊喜度 | 是否有趣？ |
| **文本对齐** | Prompt 遵循度 | 是否按指令生成？ |
| **情感传达** | 唤醒/效价 | 是否传达预期情感？ |
| **音乐性** | 和声有效性、节奏感 | 是否符合音乐惯例？ |

没有单一指标能覆盖所有维度。一首歌可能在 FAD 上得分高（分布匹配）但音乐上不连贯，或者和声有趣但音质差。

**核心矛盾**：自动指标快且可复现，但丢失音乐意义。人类评测捕捉音乐意义，但慢、贵且主观。

## 2. 人类评测协议

### 2.1 常用方法

| 方法 | 描述 | 适用场景 |
|------|------|---------|
| **MOS** (平均意见分) | 1-5 分整体质量评分 | 快速质量检查 |
| **MUSHRA** | 与隐藏参考对比评分 | 高质量对比评测 |
| **成对比较 (Pairwise)** | A vs B，哪个更好？ | 模型对比 |
| **ABX** | A vs B，隐藏参考 X | 感知差异检测 |
| **排序 (Ranking)** | 对 3+ 个样本排序 | 偏好排序 |
| **属性评分** | 对各维度分别评分（风格、连贯性等） | 多维评测 |

### 2.2 最佳实践

- **听者**：精细评测用受过音乐训练的听者；大规模偏好研究用众包（MTurk、Prolific）。
- **听音环境**：监听耳机（ATH-M50x、HD-650）或监听音箱。用 ITU-R BS.1770 统一响度。
- **样本时长**：质量/风格检查用 10–30s；连贯性用 30s–3min；端到端用完整曲目。
- **随机化**：随机化样本顺序避免位置偏差。
- **一致性**：报告 Cohen's kappa 或 ICC。低一致性说明该维度本身主观。
- **听者数量**：MOS 至少 20–30 人。多维评分需要更多。

### 2.3 大规模评测基准

| 基准 | 描述 | 规模 |
|------|------|------|
| **MUSECA** | 音乐生成对比听力测试 | 多模型、多评审 |
| **SongBench** | 带监督质量标签的歌曲生成 | 1K+ 曲目 + 人类评分 |
| **ICASSP 2025 人类偏好研究** | 通过人类偏好研究基准化音乐生成模型 | 系统成对比较 |
| **AAAI 2025 偏好对齐** | 对齐训练的人类偏好数据 | 偏好对 |

## 3. 自动指标总览

### 3.1 指标分类

```
自动指标
├── 分布指标    (FAD, FD, precision/recall)
├── 嵌入指标     (CLAP Score, FSD)
├── 感知指标     (PEMO-Q, ViSQOL)
├── 音乐特有指标 (Chroma-based, 和声, 节奏)
└── 文本对齐指标 (CLAP Score, FA-CLAP)
```

### 3.2 指标评估维度

| 维度 | 问题 |
|------|------|
| **与人类相关性** | 高分 = 人类偏好？ |
| **参考需求** | 是否需要真实音频参考？ |
| **计算成本** | 是否需要跑大模型前向传播？ |
| **维度覆盖** | 质量？风格？对齐？连贯性？ |
| **鲁棒性** | 在不同音乐类型下是否稳定？ |

没有任何指标能在所有五个维度上表现良好。

## 4. 分布指标

### 4.1 Fréchet Audio Distance (FAD)

计算音频嵌入的多元高斯分布之间的 Fréchet 距离：

- $\mu_r, \Sigma_r$: 真实音频嵌入的均值和协方差
- $\mu_g, \Sigma_g$: 生成音频嵌入的均值和协方差
- **越低越好**：生成分布越接近真实分布

**嵌入骨干**：VGGish, YAMNet, CLAP, EnCodec 特征, 音乐专用模型。

**常见陷阱**：
- FAD 对嵌入选择敏感。VGGish-based FAD 和 CLAP-based FAD 可能给出非常不同的排序。
- FAD 衡量分布匹配，不衡量单个音轨质量。模型可以 FAD 好但偶尔出坏样本。
- FAD 不衡量文本-音频对齐。

### 4.2 Precision 和 Recall

| 指标 | 描述 |
|------|------|
| **Precision** | 生成样本中落在真实分布内的比例（避免离群值） |
| **Recall** | 真实分布中被生成样本覆盖的比例（避免模式坍缩） |

高 precision + 低 recall = 安全但无聊。高 recall + 低 precision = 多样但不可靠。两者都应报告。

## 5. 嵌入指标

### 5.1 CLAP Score

使用 CLAP 模型的音频-文本对齐分数：

$$
CLAPScore(a, t) = cosine\_similarity(CLAP_{audio}(a), CLAP_{text}(t))
$$

- **Average CLAP Score**: 生成音频与其文本条件的余弦相似度均值。越高越好。
- **按风格分解**: 按风格标签分解，检查对齐是否在各流派间均匀。
- **局限**：CLAP 在通用音频上训练，非音乐专用。CLAP Score 与人类判断在某些维度上相关，但不是全部。

### 5.2 FA-CLAP (Fréchet Audio-CLAP Distance)

在 CLAP 嵌入空间中计算的 FAD，同时捕捉分布匹配和文本条件质量。

### 5.3 Frechet Style Distance (FSD)

在风格特定的嵌入空间（如流派分类器特征、风格嵌入）中计算的 FAD。衡量生成输出匹配目标*风格*分布的程度，而非整体真实分布。

## 6. 感知音频质量指标

### 6.1 常用感知指标

| 指标 | 全称 | 衡量内容 | 需要参考 |
|------|------|---------|---------|
| **PEMO-Q** | 感知音频质量评估 | 感知质量（ITU-R 标准） | 是 |
| **ViSQOL** | 虚拟语音/音频质量主观听感 | 感知相似度 | 是 |
| **Mel-distance** | Mel 频谱 L1/L2 距离 | Mel 频谱匹配 | 是 |
| **STFT loss** | 短时傅里叶变换损失 | 频谱匹配 | 是 |

**关键发现**：基于参考的感知指标（PEMO-Q, ViSQOL）与人类对*音频质量*的判断相关性高于频谱图损失。但它们需要高质量参考音频，而创意生成通常没有。

### 6.2 无参考场景

没有真实参考时（创意生成）：
- **无参考指标**：BRISQUE, NIQE（图像衍生，适配到频谱图）
- **自监督特征**：EnCodec 重建质量、音频编解码器码率效率
- **分布指标**：FAD、precision/recall（不需要参考）

## 7. 音乐特有指标

这些指标捕捉超越音频质量的音乐特性：

### 7.1 和声指标

| 指标 | 描述 |
|------|------|
| **和弦相似度** | 比较生成与参考的和弦（如果条件是和弦级） |
| **和声变化率** | 每小节和弦变化次数 — 匹配目标风格 |
| **调性一致性** | 在预期调性内的时间比例 |
| **调性稳定度** | 音高类随时间的熵 — 越低越调性 |

### 7.2 节奏指标

| 指标 | 描述 |
|------|------|
| **节拍对齐** | 生成节拍与预期节拍位置的相关性 |
| **律动一致性** | Swing 比例、微时值标准差 |
| **速度稳定度** | 时间上的 BPM 方差 |
| **音符密度** | 每拍事件数 — 匹配流派规范 |

### 7.3 旋律指标

| 指标 | 描述 |
|------|------|
| **音高直方图匹配** | 音高类分布与目标风格的相似度 |
| **音程分布** | 各音程频率 — 调性音乐呈 Zipf 分布 |
| **音域** | 半音范围 |
| **轮廓匹配** | 旋律轮廓分类匹配度 |

### 7.4 结构指标

| 指标 | 描述 |
|------|------|
| **重复度** | 自相似矩阵密度 — 匹配流派预期 |
| **段落边界检测** | 自动段落变化检测（边界 F-measure） |
| **段落比例** | Intro/Verse/Chorus/Bridge 长度匹配流派模板 |

## 8. 文本-音频对齐

### 8.1 常见失败模式

| 失败类型 | 示例 |
|----------|------|
| 忽略风格 | Prompt: "fast metal" → 输出: 慢氛围音乐 |
| 忽略情绪 | Prompt: "sad piano" → 输出: 中性钢琴 |
| 忽略结构 | Prompt: "verse-chorus" → 输出: 无明显段落 |
| 幻觉乐器 | Prompt: "violin solo" → 输出: 没有小提琴 |

### 8.2 衡量方法

| 方法 | 描述 |
|------|------|
| **CLAP Score** | CLAP 音频和文本嵌入的余弦相似度 |
| **FA-CLAP** | CLAP 空间中的 FAD（分布 + 对齐） |
| **LLM-as-judge** | 用 LLM 比较生成音频描述与 prompt |
| **属性准确率** | 对生成音频分类特定属性（BPM、调性、流派），与 prompt 对比 |
| **人类对齐评分** | "生成音乐是否遵循了 prompt？" |

### 8.3 对齐-质量权衡

更强的文本条件（更高 CFG scale）可以改善 prompt 遵循但损害音乐质量和多样性。找到合适的 CFG scale 是任务依赖的。

## 10. 指标与人类判断的鸿沟

### 10.1 已知偏差

| 场景 | 自动指标 | 人类判断 | 原因 |
|------|---------|---------|------|
| 高 FAD + 人类偏好生成 | FAD 好 | 偏好生成 | FAD 对嵌入选择敏感；人类判断音乐性 |
| 低 FAD + 人类偏好真实 | FAD 好 | 偏好真实 | FAD 衡量分布而非个体质量 |
| 高 CLAP Score + 风格错误 | 对齐好 | 风格错误 | CLAP 捕捉粗略语义，不捕捉细粒度风格 |
| FAD 好 + 音乐不连贯 | 分布好 | 不连贯 | FAD 不建模音乐结构 |

### 10.2 鸿沟持续存在的原因

1. **指标优化相关性而非因果**：指标拟合人类数据但不建模*为什么*人类偏好某物。
2. **音乐是文化和主观的**："好听"取决于听者背景、文化背景和听音目的。
3. **指标丢失时间结构**：FAD 和 CLAP Score 在片段级嵌入上操作，丢失乐句级和段落级的音乐连贯性。
4. **没有指标捕捉"惊喜"**：音乐趣味性来自期望违背（Meyer 理论），这本质难量化。
5. **参考依赖**：最佳指标需要参考音频，但创意生成没有真实参考。

### 10.3 当前研究方向

| 方向 | 方法 |
|------|------|
| 音乐专用嵌入 | 训练捕捉音乐结构的嵌入（MERT 变体、MusicFM probes） |
| 多维指标 | 按维度分离指标，而非一个总分 |
| LLM-based 评测 | 用具有音乐知识的 LLM 评估连贯性、风格等 |
| 音乐感知指标 | 将语音感知指标（PEMO-Q）适配到音乐 |
| 人机混合 | 用指标做筛选 + 人类做最终判断 |

## 11. 实践建议

### 模型开发者：

- **至少报告 FAD + CLAP Score** 作为最低可行自动评测。它们是领域标准。
- **同时报告 precision 和 recall** 以检测模式坍缩。
- **按风格分解 FAD/CLAP Score** 检查各流派性能是否均匀。
- **加入相关音乐特有指标**（如和弦条件生成的和弦准确率，节拍条件的 BMA）。
- **包含人类评测** — 即使是 20 个听者也能提供信号。
- **报告听者一致性** 来上下文化人类评测结果。

### 评测框架设计者：

- 使用覆盖多种流派、情绪和结构复杂度的多样化测试集。
- 同时包含简单和挑战性条件。
- 可能时提供参考音频（即使是合成/渲染的）。
- 发布评测代码和生成样本以保证可复现。
