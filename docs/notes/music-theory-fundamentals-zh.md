# AI 音乐研究乐理基础

[English](music-theory-fundamentals.md)

本文把音高、和声、节奏、织体和曲式映射到音乐信息检索（MIR）与音乐生成。和声示例主要描述西方调性实践，不能作为所有音乐传统的通用规则。定义和示例计算核对日期：2026-09-19。

## 1. 音高

### 1.1 频率与调律

音高是一种听觉感知属性。对于周期性乐音，它通常对应基频；即使频谱中缺少基频分量，人仍可能听到相应音高。噪声和非谐性声音的音高可能不明确。参见 [UNSW 声学解释](https://phys.unsw.edu.au/jw/musFAQ.html)。

十二平均律（12-TET）将频率比为 2:1 的八度分成 12 个相等半音。取 A4 = 440 Hz，MIDI 音符编号为 $m$：

$$
f(m)=440\,2^{(m-69)/12},\qquad m=69+12\log_2(f/440).
$$

因此 MIDI 69 为 440 Hz，MIDI 60 约为 261.63 Hz。移调 $n$ 个半音时，频率乘以 $2^{n/12}$。公式依赖这里指定的调律；实际系统可使用其他标准音高、弯音或律制。参见 [UNSW 频率与 MIDI 换算](https://phys.unsw.edu.au/jw/notes.html)。

### 1.2 音高类、八度与等音

采用 C4 = 中央 C 的记法时，MIDI 0–127 对应 C−1–G9。不同软件可能显示不同的八度编号，需要消除歧义时应交换 MIDI 编号或频率。音高类把相隔八度的音归为一类；十二音高类表示中可用 $m\bmod12$，其中 C = 0。

C♯ 与 D♭ 在十二平均律中等音，但拼写可以表达不同的和声功能。Chroma 向量舍弃八度和音名拼写；其 12 维通常聚合频谱能量，不一定是音符计数。这些不变性有利于检索，也限制了记谱和声部分析。

## 2. 音程与音阶

### 2.1 音程

音程包含度数与性质。半音数不能唯一决定其记谱名称：C–F♯ 为增四度，C–G♭ 为减五度。

| 十二平均律半音数 | 常见音程名称 |
|---|---|
| 0 | 纯一度（P1） |
| 1 / 2 | 小 / 大二度（m2 / M2） |
| 3 / 4 | 小 / 大三度（m3 / M3） |
| 5 | 纯四度（P4） |
| 6 | 增四度 / 减五度（A4 / d5），三全音 |
| 7 | 纯五度（P5） |
| 8 / 9 | 小 / 大六度（m6 / M6） |
| 10 / 11 | 小 / 大七度（m7 / M7） |
| 12 | 纯八度（P8） |

**属七和弦**的三音与七音构成三全音；不能推广到所有七和弦。协和性和张力还受排列、音色、音乐上下文和听觉经验影响。

### 2.2 大调、小调与调式

下表从主音列到高八度主音；1 表示半音，2 表示全音。

| 音阶 | 相邻音程 | 以 A 为主音的示例 |
|---|---|---|
| 大调 | 2, 2, 1, 2, 2, 2, 1 | A B C♯ D E F♯ G♯ A |
| 自然小调 | 2, 1, 2, 2, 1, 2, 2 | A B C D E F G A |
| 和声小调 | 2, 1, 2, 2, 1, 3, 1 | A B C D E F G♯ A |
| 上行旋律小调 | 2, 1, 2, 2, 2, 2, 1 | A B C D E F♯ G♯ A |

古典旋律小调练习通常下行使用自然小调；爵士旋律小调通常上下行均保留升高的六、七级。和声小调升高七级后可构成 V 与 vii°7：A 小调中为 E–G♯–B 与 G♯–B–D–F。其 ii 级七和弦是 **B–D–F–A，半减七和弦**，不是全减七和弦。

自然调式包括 Ionian、Dorian、Phrygian、Lydian、Mixolydian、Aeolian、Locrian。比较时应采用**相同主音**：Dorian 相比自然小调升高六级；Phrygian 有降二级；Lydian 相比大调升高四级。情绪形容是听感联想，不是定义。参见 [Open Music Theory 音阶材料](https://openmusictheory.github.io/scales.html)。

### 2.3 其他音高集合

- **五声音阶**指一个八度内五个音，不一定没有半音。大调五声为 1、2、3、5、6；小调五声为 1、♭3、4、5、♭7。
- **全音音阶**由六个相距全音的音组成。
- **八声音阶／减音阶**交替使用半音与全音，含八个音高类。
- 常见的**小调布鲁斯音阶**为 1、♭3、4、♭5、5、♭7。实际蓝音与弯音可以偏离这个记谱网格。

音阶掩码可约束生成结果，但不能单独表达一种传统的旋律语法、音准习惯与装饰法。

## 3. 和声

### 3.1 三和弦与七和弦

原位三度叠置三和弦包含根音、三音和五音。下列数字是十二平均律下相对根音的半音数。

| 性质 | 半音偏移 | 示例 |
|---|---|---|
| 大三 | 0, 4, 7 | C E G |
| 小三 | 0, 3, 7 | C E♭ G |
| 减三 | 0, 3, 6 | C E♭ G♭ |
| 增三 | 0, 4, 8 | C E G♯ |
| 大七 | 0, 4, 7, 11 | C E G B |
| 属七 | 0, 4, 7, 10 | C E G B♭ |
| 小七 | 0, 3, 7, 10 | C E♭ G B♭ |
| 半减七 | 0, 3, 6, 10 | C E♭ G♭ B♭ |
| 全减七 | 0, 3, 6, 9 | C E♭ G♭ B𝄫 |

B𝄫 的拼写有意义：它是 C 上方的减七度。和弦性质与和声功能不同；属七性质的和弦并非在所有风格中都担任 V。参见 [Open Music Theory：三和弦与七和弦](https://openmusictheory.github.io/triads.html)。

九、十一、十三度是复音程，对应的音高类分别与二、四、六度相同。小七和弦也可以加延伸音：Dm9 = D–F–A–C–E。选音和排列取决于上下文，并不存在“小七和弦不能加九音”的规则。

### 3.2 功能和声与终止式

在常规调性实践中，I/i 提供主功能，ii/IV 常提供属前功能，V/vii° 常提供属功能。常见路径是 I–IV–V–I；iii、vi 的角色需结合上下文。V7 常解决至 I/i，也会出现阻碍解决、属功能延长及其他走向。因此 V–I 次数不能作为通用质量指标。

| 终止式 | 典型调性实现 |
|---|---|
| 完满正格（PAC） | V–I 或 V–i，两和弦均为原位，最终高声部落主音 |
| 不完满正格（IAC） | 未满足 PAC 条件的正格终止；具体分类随教材不同 |
| 半终止（HC） | 乐句结束于 V |
| 阻碍／伪终止 | V 转向预期主和弦的替代，常见大调 vi、小调 VI |
| 变格终止 | IV–I，或小调 iv–i |

终止式依赖乐句结束的上下文，并非所有 V–I 都构成终止。参见 [Open Music Theory：终止式](https://openmusictheory.github.io/cadenceTypes)。

### 3.3 声部进行

声部进行追踪每个声部如何跨和弦移动。C 大调 G7–C 中，B 通常半音上行到 C，F 半音下行到 E；G 可以保留为共同音，D 可到 C 或 E。小调中的倾向音不同：G7–Cm 的 F–E♭ 是全音下行。参见 [Puget Sound 七和弦声部进行](https://musictheory.pugetsound.edu/mt21c/VoiceLeadingSeventhChords.html)。

避免平行纯五度、纯八度是特定对位风格的惯例，不能套用为摇滚强力和弦、管弦乐重奏或平行和弦织体的全面禁令。评测应针对目标风格，并在表示中保留声部身份。

## 4. 节奏、节拍与速度

全、二分、四分、八分、十六分音符的相对时值为 1、1/2、1/4、1/8、1/16。附点增加原时值的一半。实际秒数依赖速度及其拍单位：四分音符 = 120 BPM 时，四分音符长 0.5 秒。

**简单拍子**每拍二等分，例如 2/4、3/4、4/4、2/2、3/8。**复合拍子**每拍三等分：通常 6/8 含两个附点四分音符拍，9/8 含三个，12/8 含四个。这里的分子计数八分音符细分，不能解释为“三连音组数”。7/8 = 2+2+3 等加法分组需另外记录。参见 [Open Music Theory：节拍](https://openmusictheory.github.io/meter.html)。

基本 4/4 层级中，第 1 拍最强、第 3 拍次强、第 2、4 拍较弱；backbeat 可以在这个层级上强调第 2、4 拍。记谱层级与实际重音是不同信号。

**连音（tuplet）**指定非常规细分；三连音只是其中一种，常见为三个音占两个同类音符的时值。6/8 的普通三八分音符组无需三连音记号。**切分**在预期节拍重音之外制造强调或延续。**Swing**包含不均等细分及声部间时间关系，随速度、演奏者和上下文变化；2:1 只是示例，并非固定标准。

Adagio、andante、allegro、presto 等速度术语描述宽泛的速度与性格，没有统一 BPM 边界。数据应记录 BPM 的拍单位、必要的表情时序，并在节拍跟踪中报告半速／倍速歧义。

## 5. 旋律、期望与结构

旋律轮廓抽象出上行、下行与同音；可用上行、下行、拱形、波动等形状描述。音程统计依赖语料和表示方式；小音程较常见不等于存在普适 Zipf 定律。

**动机**是可辨认的音乐构思，既可包含音高，也可主要由节奏构成，没有固定“2–8 个音”的长度。它可通过模进、倒影、逆行、扩大与缩小发展。**乐句**是被感知为一个单位的音乐片段；某些曲目常用四或八小节，但这不是必要条件。

期望与节奏、音区、力度、上下文共同影响张力与释放。音高／音程熵衡量分布不确定性，不能直接衡量无聊、创造性或音乐质量。随机序列可以高熵，有意义的重复也可以低熵。

## 6. 织体、乐器与声音

| 织体 | 定义 |
|---|---|
| 单声 | 一条旋律线，可包含同度／八度重奏 |
| 主调 | 主旋律配伴奏，或声部主要同步运动 |
| 复调 | 多条相对独立的旋律线 |
| 支声 | 同一旋律的变体同时演奏 |

同一合奏或文化传统可以使用多种织体。弦乐四重奏不自动等于复调，中国音乐也不全是支声。

标准 88 键钢琴音域为 A0–C8（MIDI 21–108）。须区分**记谱音高**与**实际音高**：降 B 单簧管／小号通常比记谱低大二度；F 调圆号通常比记谱低纯五度。乐器音域随型号、技法和演奏者变化。MIDI 播放一般已表达实际音高，不能只因音色名是“单簧管”就再次移调；乐谱转 MIDI 时应依据原谱记法处理。

音色涉及频谱形状、瞬态、噪声和时间变化。ADSR 是合成器包络模型：attack、decay、release 是时间，sustain 是按住音符时保持的**电平**。弦乐、管乐根据奏法可以有锐利或缓慢的起音。

Bass、midrange、presence 等混音频带名称的边界近似且有重叠。乐器和人声共享大量频段，音源分离不等于频带滤波。去除 20 kHz 以上成分是滤波，不是数学意义的无损压缩；能否节省计算取决于重采样和模型设计。

## 7. 心理声学

听觉的频率选择性与掩蔽有助于解释感知并设计音频模型。Bark 临界频带与 ERB 听觉滤波器尺度有关联但不相同；实现中采用固定滤波器数量是一种建模选择。掩蔽阈值和时间范围依赖电平、频谱、时长与听者。Mel 滤波器组近似感知频率间距，不等同于完整的掩蔽模型。

音乐生成应在感知指标的验证范围内使用它们，并结合听评。编解码器音质分数不能证明和声或结构质量。参见[音乐评测](music-evaluation-zh.md)。

## 8. 曲式

| 曲式 | 示意结构 |
|---|---|
| 二段 | A–B |
| 三段 | A–B–A |
| 主副歌 | 主歌–副歌–主歌–副歌–桥段–副歌 |
| AABA | A–A–B–A；32 小节示例由四个八小节段落组成 |
| 回旋 | A–B–A–C–A |
| 奏鸣曲式 | 呈示–展开–再现，可带引子和尾声 |

以上是有大量变体的结构示意。副歌不必以 PAC 结束、主歌不必半终止、桥段不必伪终止。段落标注应结合歌词、旋律、配器、重复与和声上下文。

## 9. AI 系统中的记谱与编码

| 表示 | 优点 | 主要注意事项 |
|---|---|---|
| MIDI 类事件序列 | 音符、时间、力度、控制器事件 | 节拍／声部／拼写信息取决于编码设计 |
| REMI 类 token | 显式小节／位置，可选速度／和弦信息 | 量化和和弦估计误差可传递给模型 |
| 复合 token | 组合事件属性以缩短序列 | 需指定属性对齐和同时事件顺序 |
| Piano roll | 音高 × 时间激活网格 | 时间量化；奏法和同音重奏需额外编码 |
| ABC | 可读文本记谱，支持多声部等特征 | 支持程度取决于解析器，不表达音频音色 |

神经**音频** token 并不内置十二平均律假设；它们编码声音，可以保留连续音准。单纯音符／音高类编码若无扩展才会施加此限制。MIDI 也有弯音和调律机制。

调性估计可将观测音高类分布与移位后的大小调模板比较；学习系统还能利用时间上下文。Krumhansl–Schmuckler 类方法使用调性 profile，不是统一二值模板或音程直方图。二值模板是另一种基线选择。报告时需注明数据集、调律、调性标签集、窗口与评分协议，不存在“钢琴 90%／管弦乐 60–70%”的通用准确率保证。
